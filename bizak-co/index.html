    A PRACTICAL IMPLEMENTATION PLAN

    Automation around
    the jeweler’s judgment.

    Three possible actions to discuss with the team. Existing systems, needs and access are still to be confirmed.

    1. 01

      Give every inquiry a piece ID.

      Link an approved website or WhatsApp inquiry to the exact catalog reference, its question and its owner.

      In this preview: creating a case links it to a real reference and saves it locally.
    2. 02

      Prepare the facts. Keep approval human.

      Gather current availability, condition notes and media before a jeweler approves the response or negotiates an offer.

      In this preview: three review checks unlock a source-linked draft. No offer is accepted.
    3. 03

      Follow up only while it makes sense.

      Schedule a next action and stop it when a reply arrives, the person opts out, or the unique piece is unavailable.

      In this preview: a handoff creates a 24-hour task; stop events cancel it immediately.

    Working here. Connected later.

    The local rules, records, exports and task queue work now. A production system would require approved access to the actual tools, data mapping, testing and human sending controls.
