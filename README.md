# Propuestas comerciales de Samuel Acuña

Landings de productos y herramientas comerciales creadas como propuestas independientes. Cada carpeta contiene una experiencia distinta, con sus fuentes públicas y archivos necesarios para ejecutarla.

No son las webs oficiales de las marcas ni están conectadas a sus inventarios, pagos o sistemas internos. Los enlaces a canales oficiales abren la consulta; no envían pedidos automáticamente. Las imágenes, marcas y datos de producto pertenecen a sus titulares; se usan para presentarles esta propuesta, sin transferir derechos sobre esos activos.

Para probar localmente: `python3 -m http.server 8080` y abrir la carpeta de la propuesta en el navegador. Las páginas se publican mediante GitHub Pages desde la rama main.

Investigación y decisiones por sector: carpeta research. Cada experiencia documenta fecha y fuente de precios cuando los muestra. Se confirman con el negocio antes de comprar.

Autor de la propuesta y del código: Samuel Acuña.

## Propuesta de financiación · Manuela López

[Ver propuesta de préstamo privado entre sociedades de inversores](https://samuelacuna12.github.io/propuestas-comerciales/zapateria-manuela-lopez/).

Capital de COP 200 millones, plazo de seis meses, interés propuesto del 4% mensual y devolución completa del capital al mes seis. Incluye ocho escenarios, simulador, calendario de pagos y descarga CSV. Precio y costos suministrados por Samuel; proyecciones sujetas a los supuestos visibles. Metodología en [research/manuela-lopez-inversion.md](research/manuela-lopez-inversion.md).
